# Test Automation Report - AVICOM SauceDemo

## 📌 Project Overview
* **Framework:** Java, Selenium WebDriver, TestNG, Maven
* **CI/CD Tool:** Jenkins (Dockerized)
* **Execution Mode:** Headless Chrome (`--headless=new`)

## 🧪 Tested Scenarios
1. **Login Test:** Valid and invalid user login validation.
2. **Inventory Test:** Product sorting, adding items to the cart.
3. **Cart & Checkout Test:** Completing the checkout flow successfully.
